# 个人作品网站 · 设计规划 v0.1

> 配套原型：`prototype/index.html`（首页）、`prototype/app.html`（产品详情页模板）。
> 原型里的作品名、数据、文案都是示例，确认方向后换成真实内容。

---

## 1. 网站要做好的几件事

这个网站不只是作品集，它在实际运营里有几个具体用途。设计的优先级按这个顺序排：

| # | 用途 | 对设计的要求 |
|---|------|-------------|
| 1 | **把访客导到下载/游玩** | 每件作品都有醒目的 App Store 按钮或微信小程序码，首屏就能看到全部作品 |
| 2 | **满足 App Store 上架要求** | 每个 App 都要有「技术支持网址」和「隐私政策网址」，详情页直接承担这两个用途 |
| 3 | **建立个人品牌** | 统一的视觉识别、更新日志、关于我，让人记住「这是同一个人做的」 |
| 4 | **收集反馈和订阅** | 邮件、公众号、订阅新作通知 |

## 2. 信息架构

```
/                         首页（单页长滚动，见下方模块）
├── /apps/<slug>          产品详情页（每款 Mac / iPhone 应用一页）
│     ├── #support        技术支持（填进 App Store Connect）
│     └── #privacy        隐私政策（填进 App Store Connect）
├── /games/<slug>         小游戏详情页（小程序码、玩法、更新）
├── /changelog            完整更新日志（+ RSS：/changelog.xml）
├── /about                关于我 + 媒体资料包（图标、截图、简介下载）
└── /en/...               英文版（第二阶段）
```

### 首页模块（自上而下）

| 模块 | 作用 | 关键信息 |
|------|------|---------|
| 菜单栏导航 | 仿 macOS 菜单栏，品牌名加粗在最左（像 macOS 里当前 App 的名字） | 精选 / Mac / iPhone / 小游戏 / 更新日志 / 关于；右侧主题切换、语言、实时时钟 |
| Hero | 一句话说清楚「我是谁、做什么」 | 标题、简介、两个按钮；右侧用 **macOS 桌面小组件** 展示评分、作品数、玩家数 |
| **Dock** | 全站最有记忆点的交互：所有作品图标排成一条 Dock，鼠标靠近会像 macOS 一样放大，点击弹跳后滚到对应作品 | 按 Mac / iPhone / 小游戏 三组，用分隔线隔开；「运行中」小圆点标出最近更新的作品 |
| 本月主推 | 放最想推的一款，讲透 | 大标题卖点、3 条要点、系统要求、价格、下载按钮；右侧是用 HTML/CSS 画的真实界面示意 |
| Mac 小工具 | 卡片网格，每张卡片带一个迷你界面预览 | 图标、名称、版本 · 系统要求 · 大小、价格、评分；最后一格是「开发中」的下一款作品和进度条 |
| iPhone 应用 | 三台 iPhone 外框，屏幕里是 App 界面 | 跟随网站深浅色切换（顺便展示 App 支持深色模式） |
| 微信小游戏 | 游戏封面 + 微信小程序码（太阳码） | 「微信扫码即玩」「或在微信里搜索 XXX」、累计玩家、关卡数 |
| 更新日志 | 证明作品都还活着 | 最近 5 条：日期、作品、版本号、改了什么 |
| 关于 + 联系 | 人设和联系方式 | 简介、技术栈；联系方式做成 macOS「系统设置」风格的列表；订阅新作通知 |
| 页脚 | 法务和导航 | 技术支持、隐私政策、媒体资料包、ICP 备案号 |

### 产品详情页模板

图标 + 名称 + 一句话卖点 → 下载按钮（App Store / 官网直装版）+ 评分 → 截图横向滑动 → 功能 6 宫格 → 信息表（版本、大小、兼容性、语言、价格）+ 快捷键表 → 版本历史 → 常见问题 → **技术支持 / 隐私政策** → 其他作品。

## 3. 视觉方向

**一句话：网站本身就是一台 Mac 桌面。** 菜单栏是导航，Dock 是作品目录，每件作品放进它所属平台的“外框”里展示（Mac 窗口、iPhone、微信小程序码卡片）。这样炫酷感来自你的作品本身，而不是套模板。

- **深色优先，浅色同样完整**：跟随系统，右上角可手动切换。
- **极光背景**：首屏背景的光晕颜色取自作品图标（橙 = Mac、蓝 = iPhone、绿 = 微信），再叠一层淡网格。
- **毛玻璃**：菜单栏、Dock、桌面小组件、弹出面板都用 `backdrop-filter`，接近 macOS 26 的 Liquid Glass。
- **三类作品各有识别色**：Mac 橙、iPhone 蓝、微信绿。标题里的「小工具」「小游戏」也用这两种渐变色。
- **字体**
  - 标题：Bricolage Grotesque（英文、数字）+ 苹方 / 思源黑体（中文）
  - 正文：系统字体（Mac 上是苹方，Windows 上加载思源黑体）
  - 数据、版本号：JetBrains Mono
  - 小游戏标题：站酷快乐体；成语游戏：马善政毛笔体
- **动效**（都遵守「减少动态效果」系统设置）
  - Dock 放大 + 点击弹跳（主角，只此一处做重）
  - 卡片跟随鼠标的光斑
  - 首屏元素轻微上浮入场、极光缓慢漂移
  - 小游戏封面里的小动画（方块抖动、小猫跳跃）

参考气质：Raycast、Linear、Apple 产品页、Rauno Freiberg 的个人站。

## 4. 内容模型

每件作品一个 Markdown 文件，首页和详情页都从这里读数据，新增作品只需加一个文件：

```yaml
# src/content/apps/floaty.md
name: Floaty
nameZh: 浮窗
platform: mac            # mac | ios | wechat-game
tagline: 复制过的东西，一个都不会丢。
icon: ./floaty/icon.png  # 1024×1024 原图
colors: ["#FFC15C", "#FF6A2B"]
version: 2.4.0
updatedAt: 2026-10-08
minOS: macOS 13
size: 4.1 MB
price: 免费，Pro 永久 ¥18
appStoreId: "1234567890"   # 用于下载链接和 Smart App Banner
rating: { score: 4.8, count: 1026 }
featured: true
screenshots: [./floaty/shot-1.png, ./floaty/shot-2.png]
---
正文：功能介绍、FAQ、隐私政策……
```

小游戏另有字段：`wxSearchName`（微信搜索名）、`miniCode`（小程序码图片）、`players`、`levels`。

## 5. 技术方案（建议）

| 项目 | 选择 | 理由 |
|------|------|------|
| 框架 | **Astro** | 纯静态输出、加载快；Content Collections 正好对应上面的内容模型；需要交互的地方（Dock）用少量原生 JS |
| 样式 | 原生 CSS + CSS 变量 | 原型里的设计令牌可以直接搬过去 |
| 部署 | Cloudflare Pages 或 Vercel | 免费、自动 HTTPS、推送即部署 |
| 国内访问 | 如果主要用户在国内：腾讯云 EdgeOne / COS + CDN，需要 **ICP 备案** | 海外托管在国内访问速度不稳定 |
| 统计 | Umami 或 Plausible | 轻量，不需要 Cookie 弹窗 |
| 订阅 | Buttondown / 自建 | 新作上架时发邮件 |

### 平台相关的细节

- **iPhone Safari 顶部下载横幅**：详情页加 `<meta name="apple-itunes-app" content="app-id=...">`，iPhone 用户打开网页会出现系统原生的「打开 / 获取」横幅。
- **官方下载徽章**：上线时换成 Apple 官方提供的 App Store / Mac App Store 徽章（Apple 营销资源网站可以下载），原型里用的是占位按钮。
- **微信小游戏**：网页无法直接拉起小游戏，主要靠**小程序码**（在微信公众平台后台生成）和「微信搜一搜」。如果需要从站外跳转，可以调研微信官方的 URL Scheme / URL Link 能力，上线前要确认它对小游戏是否支持。
- **在微信里打开网站**：微信内置浏览器里不能跳转 App Store，需要显示「点右上角，在浏览器打开」的提示层。
- **SEO 和分享**：每页生成 Open Graph 分享图（作品图标 + 名称），在微信、Twitter 里分享时有卡片预览。

## 6. 里程碑

1. **确定原型方向**（当前）：确认整体风格、模块取舍、配色。
2. **搭建骨架**：Astro 项目、设计令牌、菜单栏、Dock、详情页模板。
3. **填充真实内容**：作品图标、截图、文案、小程序码、隐私政策。
4. **上线**：域名、部署、统计、提交 App Store Connect 的支持和隐私网址。
5. **第二阶段**：英文版、博客/开发日记、媒体资料包下载。
